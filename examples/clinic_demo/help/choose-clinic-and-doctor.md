# Choose a clinic branch and doctor

On the **Book appointment** screen, the branch list is sorted by distance when location access is on, otherwise alphabetically.

Each doctor card shows the doctor's name, specialty, languages spoken and the next available slot. Tap a card to see the doctor's full profile.

To see the earliest time across all doctors in a specialty, choose **Any available doctor**. To always see the same doctor, tap the heart on their card to add them to **Favourites**, which appear at the top of the list next time.
